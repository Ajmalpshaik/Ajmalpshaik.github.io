Revit add-in suite

AJ-Tools

47 commands I built so my team stops repeating itself.

A C# add-in suite with WPF interfaces and its own installer, so a whole drafting team runs the same version of the same tools. One codebase builds for Revit 2020 through 2027. Every command below is on the ribbon today — the descriptions are the tooltips from the source.

AJ Tools 32 tools · 12 panels

View 6

  • View CropView crop and annotation crop tools.
  • Unhide AllUnhide all elements in the active view (Temporary Hide/Isolate + hidden items).
  • Toggle LinkToggle visibility of all Revit Links in the active view.
  • Filter ProCreate parameter filters quickly (category, parameter, values) and apply them to the active view.
  • ColorizeColorize elements by category or by parameter value directly in the active view (or selected views) - no view filter is created.
  • Highlight SelectionColor the selected elements red and every other element in the active view gray, for instant visual identification.

Graphics 3

  • Apply GraphicsApply the same graphics override settings to selected elements or selected categories in the active view.
  • Match GraphicsMatch category or element graphics from a picked source.
  • Reset GraphicsReset category and element graphics overrides in the active view.

Datums 3

  • Reset Grid / Level Extents to 3DReset grid or level datum extents back to 3D.
  • Modify Level ExtentsMatch or maximize level 3D extents.
  • Flip Grid / Level BubblesToggle which datum end shows the bubble for grids or levels, one item at a time.

Modify 4

  • Match MEP Element ElevationMatch center, top, or bottom elevation from a source MEP element to others.
  • Reassign Reference LevelReassign supported MEP elements from one level to another without moving them physically - whole project, or just your current selection.
  • Pin / Unpin ElementsPin/unpin separated Sheet groups (Title Blocks, Placed Views, Legends, Schedules) with Active Sheet Only or All Sheets mode, and Model groups (Duct, Pipe, Cable Tray, Generic Models, Mechanical Equipment, Plumbing Fixtures, Electrical Equipment, Grids, Levels).
  • Smart SelectionPick one reference element, then one window or crossing-select - only elements of the same category are added.

MEP 4

  • Connect MEP ElementsConnect two same-category MEP elements (Pipe, Duct, Cable Tray) with routing and angle settings.
  • Elements to Ceiling GridPick ceiling, pick grid intersection, then snap point-based elements to nearest tile centers.
  • HVAC SchematicConvert selected ducts, air terminals, and mechanical equipment into a connector-based HVAC schematic inside a new Drafting View.
  • Pipe SizingCalculate domestic water pipe sizing from fixture units, system type, pipe material, and velocity limit.

Opening 1

  • OpeningCreate direct wall, floor/slab, and beam openings from selected pipes, ducts, cable trays, and conduits.

Coordination 3

  • Element IDElement ID tools for current and linked models.
  • 3D Views3D view creation tools.
  • Link WorksetAssign selected Revit links and CAD imports to a workset.

Data 2

  • Assign LocationAssign Room, Level, Coordinates, Altitude, and HVAC Zone data to selected categories.
  • Duct StandardCalculate and write duct sheet thickness, gauge, weight, and area based on SMACNA-style rules.

Manage 2

  • TransferTransfer tools.
  • PurgePurge tools.

Family 1

  • Shared to FamilyConvert selected shared parameters in the active family into normal family parameters.

AI Assistant 2

  • C#Open the interactive AI-powered C# shell for Revit.
  • AJ AIConnect or disconnect AJ AI - lets an external AI agent (via MCP) run C# against this

Game 1

  • Game ModeWalk inside the model like a video game, in a real Revit perspective view

AJ Annotation 15 tools · 6 panels

Auto Dimension 1

  • Auto Duct DimensionCreate a chained perpendicular reference dimension for ducts, nearby ducts, walls, structural columns, and structural beams.

Dimensions 3

  • Automatic DimensionCopy Above/Below/Prefix/Suffix text from one dimension to others.
  • Quick DimensionCopy Above/Below/Prefix/Suffix text from one dimension to others.
  • Copy Dimension TextCopy Above/Below/Prefix/Suffix text from one dimension to others.

Annotation 3

  • Duct Flow AnnotationsPlace duct flow annotations along horizontal ducts.
  • Revision CloudsCreate orthogonal stepped revision cloud boundaries aligned to dominant selected-element angle. Keeps running until Esc.
  • Copy / Swap Text NotesCopy the text value from one text note to others (click targets until ESC).

Family 1

  • Center AnnotationCenter selected annotations in the active annotation family view.

Tags 6

  • Smart MEP TagsForce tags to use a right-angle leader. Run again on the same tag to flip the elbow side. Preselect tags or pick tags (Tab cycles) until Esc.
  • Rearrange TagsForce tags to use a right-angle leader. Run again on the same tag to flip the elbow side. Preselect tags or pick tags (Tab cycles) until Esc.
  • L-Shape LeaderForce tags to use a right-angle leader. Run again on the same tag to flip the elbow side. Preselect tags or pick tags (Tab cycles) until Esc.
  • Create TagsSelect one or more MEP elements, then click a location for each to create a tag there. Skips elements already tagged in the view, shorter than the configured minimum length, or a vertical run. Press Esc to stop early.
  • Center Room TagsMove every room tag in the active view to the center of its tagged room. Handles local rooms and loaded linked rooms; skips orphaned, pinned, and unreadable tags.
  • Section Mark VisibilityAutomatically manage section visibility based on Sheet Number filters or sheet placement status.

Text 1

  • Arrange Text in BoxFit selected text notes into a box you drag: each note is resized to the box width and the notes are spread evenly top-to-bottom with left edges aligned. Pick the top-left corner once, then pick bottom-right corners to re-fit live. Press Esc to finish.
