Questions

Straight answers

The six things recruiters, consultants and contractors ask me first, in the order they ask them.

01

Are you available for BIM roles in Qatar?

Yes. I am in Doha on a transferable QID with NOC, so there is no new visa to arrange and I can join within days. Open to BIM Coordinator, BIM Modeller and MEP BIM Specialist roles with consultants and contractors anywhere in Qatar, and to automation scopes alongside a modelling role.

02

How do you run clash detection and get clashes actually closed?

Federate the disciplines in Navisworks and run rule-based tests per discipline pair, then strip out the noise before anyone sees a report — an unfiltered clash list gets ignored. What goes out is grouped by system and area, with viewpoints, an owner and a date, tracked as issues in BIM 360 or ACC and re-run every milestone so closure is proven rather than assumed.

03

Can you set up BIM standards and a BEP for a new project?

Yes — project template, shared parameters, worksets, view and sheet structure, naming to ISO 19650, a family library, and an LOD matrix tied to each milestone. The part most projects skip is enforcement, so I add model audit checks that catch drift early instead of at submission week.

04

How do you take over a model somebody else started?

Audit before touching geometry. Warnings, purge, file size, worksets, links, naming, missing parameters, and the real LOD against what the milestone claims. That becomes a short written report of what is wrong and what it costs to fix, then the fixes go in an agreed order — structural problems first, cosmetic last.

05

Can you build a tool for our team?

Yes. What I already have is built around the standards of the team I work with, so it is not sold off the shelf — but building a private version around another company’s templates, parameters and naming is straightforward, because the installer, the versioning and the multi-version build are already in place. Ask and I will tell you honestly whether a tool is worth building for your workflow, or whether what you need is a change to the template instead.

06

Do you take freelance or remote automation work?

Yes for automation — Revit add-ins, pyRevit and Dynamo, delivered remotely, scoped up front, version-controlled and handed over with documentation. Modelling and coordination I take on site in Qatar, because that work needs to sit with the project team.
