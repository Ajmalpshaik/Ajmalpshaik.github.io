01 The problem

Drafting is mostly the same hour, repeated.

Every MEP project runs on the same handful of actions done thousands of times. Tag a duct. Match the graphics. Fix a level. Renumber a run of sheets. None of it is difficult and none of it is where the value is — but it eats the day, and the coordination that actually decides whether a building works gets whatever hours are left.

I spent my first years in Doha doing exactly that, on villas and towers, in AutoCAD and then Revit. The work I was paid for was thinking. The work I actually did was typing.

02 The turn

So I stopped doing it by hand.

Rather than work through the same task again, I started building something that would do it instead. Small routines at first, nothing sophisticated, each one taking a job off my hands that I was tired of repeating.

That is the turning point, and it is not really about code. It is the realisation that the repetitive half of the work can be described precisely enough to hand over — and that the half worth keeping is the judgement. Everything since has been the same idea applied to larger problems.

  1. AutoLISPsmall routines inside AutoCAD
  2. Dynamovisual scripting against the Revit model
  3. pyRevit and Pythonproper tools, shared with the team
  4. C# add-insinstalled, versioned and supported

Each step covered more ground than the one before it. Where that line ends up is the next chapter.

04 AJ-Tools

The scripts became a product.

A personal script helps one person. The moment a tool has an installer, a version number and documentation, it helps everyone — and that is the difference between a clever trick and something a company can actually rely on.

Today AJ-Tools is a C# Revit add-in suite with WPF interfaces and its own installer, so the whole drafting team runs the same version of the same tools. One codebase builds for Revit 2020 through 2027, currently at v1.41.0. Two ribbon tabs carry 49 tools across 19 panels — AJ Tools for view, graphics, MEP and coordination work, AJ Annotation for dimensioning, tagging and text.

FAQ

Common questions. Straight answers.

Are you available for BIM roles in Qatar?

Yes. I am in Doha on a transferable QID with NOC, so there is no new visa to arrange and I can join within days. Open to BIM Coordinator, BIM Modeller and MEP BIM Specialist roles with consultants and contractors anywhere in Qatar, and to automation scopes alongside a modelling role.

How do you run clash detection and get clashes actually closed?

Federate the disciplines in Navisworks and run rule-based tests per discipline pair, then strip out the noise before anyone sees a report — an unfiltered clash list gets ignored. What goes out is grouped by system and area, with viewpoints, an owner and a date, tracked as issues in BIM 360 or ACC and re-run every milestone so closure is proven rather than assumed.

Can you set up BIM standards and a BEP for a new project?

Yes — project template, shared parameters, worksets, view and sheet structure, naming to ISO 19650, a family library, and an LOD matrix tied to each milestone. The part most projects skip is enforcement, so I add model audit checks that catch drift early instead of at submission week.

How do you take over a model somebody else started?

Audit before touching geometry. Warnings, purge, file size, worksets, links, naming, missing parameters, and the real LOD against what the milestone claims. That becomes a short written report of what is wrong and what it costs to fix, then the fixes go in an agreed order — structural problems first, cosmetic last.

Can another company use AJ‑Tools?

The suite is built around the standards of the team I work with, so it is not sold off the shelf. Adapting it, or building a private version around another company’s templates and naming, is straightforward — the installer, the versioning and the multi-version build are already in place. Ask and I will tell you honestly whether a tool is worth building for your workflow.

Yes for automation — Revit add-ins, pyRevit and Dynamo, delivered remotely, scoped up front, version-controlled and handed over with documentation. Modelling and coordination I take on site in Qatar, because that work needs to sit with the project team.
