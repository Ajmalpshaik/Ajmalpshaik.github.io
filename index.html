AJ-Tools

AJ-Tools. The Revit add-in suite I build and my team runs.

It started as AutoLISP routines to stop repeating drafting work by hand. Today it’s a C# Revit add-in suite with WPF interfaces and its own installer, so the whole drafting team runs the same version of the same tools — one codebase building for Revit 2020 through 2027, currently at v1.41.0. Two ribbon tabs: AJ Tools for view, graphics, MEP and coordination commands, AJ Annotation for dimensioning and tagging.
