Heron Tools

Everyday Revit tools for BIM modellers, on the Heron ribbon tab. The jobs a drafting team repeats every week — filters, colours, crops, datums, levels — each one a single button and a single Undo.

What is on the ribbon 17 tools · 5 panels · plus About

View 6

  • Filter ProPick categories, a parameter and its values. Filter Pro makes one view filter per value, names it for you — the name says the rule, such as “Not 300” or “Has value” — and adds it to the active view or the views you pick, first in the filter list. Shuffle colours gives every filter its own colour.
  • ColorizeThe same picks, but the colour goes straight onto the matching elements, with no view filter — by value, or whole categories. Restore original puts back the elements’ own overrides.
  • View CropCrop View by Elements fits plan crops around their elements with a margin. Annotation Crop by View Crop turns the annotation crop on at an offset measured on paper.
  • Unhide AllShows everything hidden one by one in the view, and turns Temporary Hide/Isolate off.
  • Toggle LinksTurns the RVT Links category off or on in the view, and tells you if some links stay hidden one by one.
  • HighlightThe selection in red, the rest grey. Click again and the view comes back exactly as it was — every element’s own overrides are remembered.

Quick 1

  • Quick MenuA tool wheel that opens around the mouse pointer with your favourite Heron Tools buttons and Revit commands. Quick Menu Settings chooses what sits in each slot.

Datums 3

  • Reset Datums to 3DPuts grid and level ends in the view back to their 3D extents.
  • Level ExtentsMatches level extents to another level, or stretches them to the section box.
  • Flip BubblesSwaps which end of a grid or level shows its bubble.

Modify 4

  • Match ElevationMatches the centre, top or bottom elevation of a source MEP element.
  • Reassign LevelMoves MEP elements to another reference level without moving them in space — it measures every element before and after to prove it.
  • Pin / UnpinPins or unpins whole groups at once: title blocks, views on sheets, ducts, pipes, grids, levels.
  • Smart SelectionPick one element, window-select, and keep only that category.

Coordination 3

  • Element IDSee the ID of a picked element, in links too, or find an element by its ID and zoom to it.
  • 3D Views by WorksetOne 3D view per user workset, in one press.
  • Link WorksetPuts the selected Revit links and CAD imports on a workset.
The Filter Pro window reads in the order you work

Left to right: 1 Categories · 2 Parameter · 3 Values, each with a count (“2 of 10 picked”), a search box and a hint when the list is empty. On the right, a live preview of the filter name sits above four tabs — Rule, Name, Apply and Colours — and rules that do not suit the picked parameter are switched off. Anything a run skipped is listed with the reason. A missing pick is said in the status line, never in a pop-up.

Installing it one file, no administrator

The installer HeronToolsInstaller.exe

  • One file, nothing to install firstIt runs on the .NET Framework that every Windows 10 and 11 already has.
  • It finds your RevitsEvery Revit 2020 to 2027 on the PC is listed. Tick the ones you want, and press Install. Untick and press Install to remove it again — it asks first.
  • For your Windows user onlyNo administrator rights. Revit 2027 moved the all-users add-in folder into Program Files; the per-user folder is the same on every release.
  • It never closes RevitIf one of those Revits is open, it waits, says so, and carries on by itself once Revit is closed.
  • It keeps what it replacesThe previous install is kept, put back by itself if a copy fails, and every file written is checked against the build it carries.
  • For an office with many PCsThe same file runs without a window: /install, /install /years 2024,2026, /uninstall, /status, with a log if you want one.

Why it is safe on a live model the rules the code follows

Every press 4

  • One press, one UndoEvery button that changes the model runs as one named transaction. If anything in that run fails, the whole run is rolled back and the window says, in plain words, that nothing was changed.
  • The view comes backHighlight and Colorize remember every element’s own overrides, so putting the view back is one click, not an afternoon.
  • Revit’s own thread, onlyThe Revit API is called only from Revit’s thread — the one rule that keeps an add-in from taking Revit down with it.
  • One codebase, every releaseUnits in 2021, parameter types in 2022, 64-bit element IDs in 2024, a new .NET in 2025 and again in 2027. The differences live in one place, and the build stops with a clear message for a Revit year it does not know yet.
What has been checked, and what has not

Every change is compiled against every Revit from 2020 to 2027 before it is accepted. A compile is not a Revit test, though, and version 1.0.0 is still waiting for its test inside Revit. It is not released until that is done — I will say so here and on LinkedIn when it is.

One tab, with Heron AI two products, one ribbon

Heron Tools is a stand-alone add-in. It does not need Heron AI and uses none of its code. The two only share the name of the ribbon tab — so when both are installed, their buttons sit side by side on one Heron tab, whichever one Revit happens to load first.

The tools themselves grew out of AJ-Tools, the add-in I built for my own team. Moving them here, every run became one named Undo step, every element ID became 64-bit, and a long list of small workflow faults was fixed on the way.
