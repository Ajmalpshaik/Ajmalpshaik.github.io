Heron Tools

The tools

17 tools. Zero fuss.

  • Filter ProOne view filter per value, named for you.
  • ColorizeColour elements by value. Restore in one click.
  • View CropCrop views tight around their elements.
  • Unhide AllEverything hidden in the view, back on.
  • Toggle LinksRevit links off or on in one click.
  • HighlightSelection red, the rest grey. Click again to reset.
  • Quick MenuYour favourite tools in a wheel at the cursor.
  • Reset Datums to 3DGrid and level ends back to their 3D extents.
  • Level ExtentsMatch levels, or stretch them to the section box.
  • Flip BubblesSwap the bubble end of grids and levels.
  • Match ElevationLine up MEP at centre, top or bottom.
  • Reassign LevelNew reference level. Nothing moves.
  • Pin / UnpinPin whole groups at once.
  • Smart SelectionWindow-select, keep one category.
  • Element IDFind any element by ID, in links too.
  • 3D Views by WorksetOne 3D view per workset, in one click.
  • Link WorksetPut links and CAD imports on a workset.
Install

One file. Done.

01

One installer

Finds every Revit 2020–2027 on your PC. Tick, install.

02

No admin rights

Installs for your Windows user only.

03

Never closes Revit

If Revit is open, it waits.

Safe on a live model

If it fails, nothing changes.

01

One undo per click

Every click is one named Undo step.

02

All or nothing

Any error rolls the whole run back, and it tells you.

03

Works with Heron AI

Same Heron tab. Neither needs the other.
