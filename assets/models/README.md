# Models

`parrot.glb`: the Parrot from the three.js examples
(`examples/models/gltf/Parrot.glb`, three.js r128), unchanged. Model by
[Mirada](https://mirada.com/) for [ROME, "3 Dreams of Black"](https://www.ro.me/).
Used by `assets/forest.js` for the three parrots in the forest.
