BIM Viewer

Open an IFC from Revit. Inspect it, then walk inside.

  • Free tool
  • Runs in your browser
  • File stays on your device

The BIM Viewer needs JavaScript and a browser with WebGL 2: a current Chrome, Edge, Firefox or Safari.

      From Revit

      1. 3D view, then File › Export › IFC
      2. Tick Export only elements visible in view
      3. Drop the .ifc here, or press Open IFC
